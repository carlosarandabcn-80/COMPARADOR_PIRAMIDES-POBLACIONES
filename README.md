# Pirámides poblacionales: diagnóstico metodológico y comparación

Recurso interactivo para interpretar pirámides poblacionales desde la estructura social y traducir la lectura demográfica a criterios de intervención socioeducativa.

## Qué incluye

- Diagnóstico visual por modelos de pirámide.
- Comparador sustituible entre dos estructuras poblacionales.
- Comentario guiado con síntesis breve o desarrollo ampliado.
- Traducción socioeducativa por rasgos: base, cuerpo adulto, cúspide, sexo, cohortes y muescas.
- Indicadores demográficos básicos: dependencia juvenil, dependencia de vejez, dependencia total, índice de envejecimiento y feminización de la vejez.
- Exportación del comentario en TXT, copia al portapapeles, impresión/PDF desde navegador y persistencia local de selección.

## Publicación en GitHub Pages

1. Crea un repositorio nuevo.
2. Sube todos los archivos de esta carpeta.
3. En GitHub, entra en `Settings > Pages`.
4. Selecciona `Deploy from a branch` y elige `main` / raíz del repositorio.
5. Guarda y espera a que GitHub genere la URL pública.

No requiere instalación, servidor, base de datos ni dependencias externas.

## Uso responsable

Las pirámides internas son modelos didácticos sintéticos para reconocimiento visual y comparación metodológica. Para análisis con datos reales se recomienda contrastar con fuentes estadísticas oficiales o bases demográficas verificables.
