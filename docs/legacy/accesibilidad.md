# Accesibilidad

La aplicación incorpora un botón flotante con el icono universal de accesibilidad. Desde ese botón se despliega un panel discreto con ajustes de alto contraste, texto grande, espaciado, foco lector, reducción de movimiento y lectura en voz alta del comentario orientativo.

El panel permanece oculto por defecto para no interferir con la lectura visual del recurso, pero es accesible por teclado y mediante lector de pantalla.
