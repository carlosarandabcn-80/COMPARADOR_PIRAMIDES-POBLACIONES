# Lógica metodológica

La aplicación sigue una secuencia controlada:

1. Identificar variables observables: edad, sexo, territorio, año, escala, base, cuerpo adulto, cúspide, cohortes, simetrías y muescas.
2. Formular hipótesis prudentes: natalidad, mortalidad, envejecimiento, migración, crisis, generación numerosa o cambio familiar.
3. Relacionar con estructura social: instituciones, mercado laboral, salud, cuidados, familia, desigualdad y territorio.
4. Traducir a intervención socioeducativa: población diana, actuación concreta e indicador de seguimiento.

La herramienta evita convertir una forma gráfica en causa cerrada cuando el contexto disponible no permite sostenerlo.
