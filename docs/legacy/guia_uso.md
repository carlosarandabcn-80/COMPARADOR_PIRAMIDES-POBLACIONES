# Guía de uso

## 1. Diagnóstico principal
Selecciona un modelo de referencia. El panel actualiza la forma, la base, el cuerpo adulto, la cúspide, la lectura por sexo/género, las cohortes y las consecuencias institucionales.

## 2. Comentario guiado
Elige una versión breve o un comentario desarrollado. Selecciona el énfasis de cierre: equilibrado, educación, empleo, cuidados o migración.

## 3. Comparador
Selecciona dos modelos. La matriz ayuda a justificar diferencias de base, cuerpo adulto, cúspide, sexo y cohortes.

## 4. Aplicación socioeducativa
Consulta la matriz de rasgos e intervenciones para traducir la lectura demográfica a población diana, actuaciones e indicadores.

## 5. Exportación
El botón de copia envía el comentario al portapapeles. El botón de exportación genera un archivo TXT. La impresión usa un formato optimizado para PDF.
